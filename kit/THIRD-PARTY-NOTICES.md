# Private kit attribution

The included Gradle wrapper JAR and launch scripts are Gradle components under Apache License 2.0. Copyright headers in the scripts are preserved; the accompanying license and Gradle notice are under licenses/. Those files are copied from the local pinned Gradle9.6.0 distribution without modification. No Gradle distribution, Minecraft/Forge source/runtime, JDK, cache or npm dependency is bundled in this ZIP.

Build and optional MCP dependencies are resolved from their pinned metadata/lockfiles and retain their upstream licenses. See docs/DEPENDENCIES.md. These notices do not establish an exhaustive public-distribution review or choose a license for the kit's original work; that remains a publication gate. This candidate is for the authorized private machine trial only.

The static-model starter's checker texture and pyramid mesh are original procedural sample assets, reproducible with the included Python sample generator. Downloaded model bundles, their converted assets and maintainer QA are excluded from the kit. Blender is an optional external authoring tool and is not bundled.

The RF network starter contains original Java and model JSON using references to vanilla textures supplied by the user's Minecraft installation; no Minecraft texture/source/runtime bytes or CoFH/Ender IO/Thermal code are bundled. Its Forge APIs use the existing pinned build dependency. Maintainer assertion mods and proof evidence are excluded.
