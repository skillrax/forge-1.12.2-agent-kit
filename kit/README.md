# Agentic Codex Minecraft kit

Extract the ZIP, create a Codex project using the folder containing Setup.cmd as its primary folder, then follow [START.md](START.md). Ask the agent to run setup as administrator; choose Y/N for Java settings and recommended Node.js/MCP support before downloads. Toolkit version/compatibility are in kit.json. Production src/main starts empty; the skill contains small working patterns and optional starters. This is a private beta for separate-PC testing. Follow [docs/FRESH-PC.md](docs/FRESH-PC.md); cold-PC setup and Codex app connectivity remain to be observed.
