# Agentic Minecraft mod development kit

A practical Windows kit for AI-assisted Minecraft 1.12.2 / Forge mod development. We prove representative mechanisms with small working examples, then reuse those patterns for similar features.

**Maintainers start with [TASK.md](TASK.md). Recipients start with [kit/START.md](kit/START.md).** Current version and compatibility: [kit/kit.json](kit/kit.json). This remains private development. Agent-neutral fork and return path: [docs/FORK.md](docs/FORK.md).

| Location | Role |
|---|---|
| `kit/` | Active recipient source, tools and focused Forge references |
| [docs/CAPABILITIES.md](docs/CAPABILITIES.md) | Demonstrated mechanisms, plausible extensions and gaps |
| [kit/docs/AGENT-HOSTS.md](kit/docs/AGENT-HOSTS.md) | Shared instructions, shell baseline and optional host adapters |
| [docs/REFERENCES.md](docs/REFERENCES.md) | Task-specific lookup routes |
| [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) | Small development loop and candidate stopping rule |
| [qa/README.md](qa/README.md) | Optional focused checks and preserved examples |
| `packaging/` | Recipient ZIP allowlist and packager |

`releases/`, `evidence/` and `.work/` contain local generated artifacts. Original exports, historical evidence, archive and prototype folders remain in the original workspace; see [fork boundaries](docs/FORK.md).

The full Thermal Expansion/Dynamics qualification contract was retired on 2026-10-12. Existing successful examples remain useful evidence. Future work proves new mechanisms and fixes observed kit problems; it does not recreate every reference feature or certify every variant.
